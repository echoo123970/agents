# Brand Foundation Settings

Set these in the **draft theme** editor (Theme → Customize → Theme settings) so every page
is cohesive. These are intentionally given as values to enter, not a raw `settings_data.json`,
because that file is specific to your customized theme and should be edited in-place.

## Colors (Theme settings → Colors)
Mosaic/wall art reads best on a calm, gallery-like backdrop so the artwork pops.
- **scheme-1 (default / light):** Background `#FAF8F5` (warm off-white) · Text `#1F1B16` ·
  Buttons `#1F1B16` bg / `#FAF8F5` text · Accent/links `#9A6B4F` (terracotta).
- **scheme-2 (accent band):** Background `#1F1B16` (deep charcoal) · Text `#FAF8F5` ·
  Buttons `#9A6B4F` bg / `#FFFFFF` text. Used by the trust bar + newsletter.
- Keep **borders** subtle: `rgba(0,0,0,0.08)`.

## Typography (Theme settings → Typography)
- **Headings:** a refined serif or high-contrast display face (e.g. Cormorant, Playfair).
- **Body:** a clean, legible sans (e.g. Assistant, Inter), base size **16px+**.
- Heading scale ~ **130–140%**, letter spacing default.

## Logo & favicon (Theme settings → Logo)
- Upload a high-res transparent PNG logo; set desktop logo width ~140–160px.
- Set a favicon (square, 512×512 source).

## Buttons & corners (Theme settings → Buttons / Inputs)
- Corner radius: small (4–6px) for a modern, gallery feel.
- Border thickness: 1px; consistent hover (slight darken / underline).

## Layout & spacing (Theme settings → Layout)
- Page width ~ 1400–1600px.
- Section vertical spacing: consistent (the templates use 36px top/bottom for content
  sections, 24px for tighter bands).
- Grid horizontal/vertical spacing: 12–16px.

## Cart
- Use a **drawer** cart (Theme settings → Cart → Cart type: Drawer) for a smoother,
  more "dynamic" add-to-cart experience.
